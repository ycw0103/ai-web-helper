# 🎯 AI 网页助手 Chrome/Edge 插件
基于 Ollama 本地大模型的浏览器 AI 助手插件，支持网页文本翻译、内容总结、语法解析等功能。

## ✅ 项目亮点
- 🔒 **完全本地运行**：所有 AI 计算在本地 Ollama 完成，不依赖云端，隐私安全
- ⚡ **低延迟响应**：本地 API 调用，秒级返回结果
- 🧩 **浏览器原生集成**：右键菜单一键翻译 / 总结，不影响正常浏览
- 📚 **多模型支持**：兼容 Ollama 全系列模型（llama3、qwen 等）
